# CDH Legacy Baseline — 2025–26

**Status: LEGACY — reference only**

The 2025–26 robot was a clean-sheet redesign. These choices explain the inherited architecture but are not automatically current for 2026–27.

## 2025–26 Final / Late-Cycle Baseline
- Raspberry Pi 4 Model B from 2024–25 was replaced by an **NVIDIA Jetson Orin Nano**.
- An **ESP32** was retained as a recovery/watchdog coprocessor able to reboot the Jetson.
- CDH and GNC exchanged sensor, localization, autonomy, and teleoperation data over **ROS 2**.
- The development/software baseline used **ROS 2 Humble on Ubuntu 22.04**.
- **Game controller** was selected for teleoperation input.
- **Dear PyGui** was selected for the ground-station UI.
- Telemetry, robot state, sensor feedback, and health/status were intended to be visible to the operator.
- The early SRR concept in which the ESP32 published sensors through micro-ROS was **superseded** by Jetson-hosted sensor ingestion with ESP32 watchdog/recovery.

## Historical 2024–25 Predecessor
- Onboard compute used a **Raspberry Pi 4 Model B**.
- The autonomy stack used a more standard **SLAM / Nav2** approach.
- The 2025–26 redesign intentionally replaced that compute/autonomy architecture.
