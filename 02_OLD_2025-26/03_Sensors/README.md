# Old Sensor Code — 2025–26

This folder contains the useful sensor-facing code from last season.

| File | What it did |
|---|---|
| `Camera_ROS2.py` | Subscribed to RGB, depth, IR, and point-cloud camera topics |
| `IMU_ROS2_20Hz.cpp` | Read the ISM330DLC IMU and published ROS 2 IMU data at about 20 Hz |
| `IMU_ROS2_100Hz.cpp` | Similar IMU publisher running at about 100 Hz |

**Reference only. Sensor models, buses, frames, and topics must be rechecked for 2026–27.**
