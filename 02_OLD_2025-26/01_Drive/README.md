# Old Drive Code — 2025–26

This is last season's rover-driving code.

| File | What it did |
|---|---|
| `Autonomous_Drive_ROS2.py` | Received left/right autonomous motor commands and sent them to the RoboClaw |
| `Autonomous_Drive_Test.py` | Manually published test autonomous-drive commands |
| `Tank_Drive_USB.py` | Used a game controller to drive through RoboClaw over USB |
| `Tank_Drive_UART.py` | Same idea, but through the Jetson UART |
| `Drive_Launch.py` | Started the old drive-related ROS 2 nodes |

**Reference only. Do not run this unchanged on the 2026–27 robot.**
